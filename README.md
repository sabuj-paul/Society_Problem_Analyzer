### Project Overview
The **Society Problem Reporter and Analyzer** is a web platform designed to bridge civic reporting and municipal response across Bangladesh[cite: 1, 2]. It enables citizens to report neighborhood infrastructural problems (road damage, lighting, drainage, waste)[cite: 1, 2], allows residents to endorse/upvote issues[cite: 1, 2], and dynamically calculates a **Priority Score** for Local Authorities to address high-impact issues first[cite: 1, 2].

### Tech Stack
* **HTML5**: Structural semantic layout[cite: 1, 2]
* **CSS3**: Custom property variables, CSS Grid, Flexbox[cite: 1, 2]
* **JavaScript (ES6+)**: Reactive UI state management, Priority scoring engine[cite: 1, 2]

### Running the Application
1. Download or clone the folder contents into a local folder (`society-problem-reporter`).
2. Open `index.html` in any modern web browser.
