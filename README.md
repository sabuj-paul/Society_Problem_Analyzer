### Project Overview
The **Society Problem Reporter and Analyzer** is a web platform designed to bridge civic reporting and municipal response across Bangladesh. It enables citizens to report neighborhood infrastructural problems (road damage, lighting, drainage, waste), allows residents to endorse/upvote issues, and dynamically calculates a **Priority Score** for Local Authorities to address high-impact issues first.

### Tech Stack
* **HTML5**: Structural semantic layout
* **CSS3**: Custom property variables, CSS Grid, Flexbox
* **JavaScript (ES6+)**: Reactive UI state management, Priority scoring engine

### Running the Application
1. Download or clone the folder contents into a local folder (`society-problem-reporter`).
2. Open `index.html` in any modern web browser.
